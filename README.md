## 🚀 使用说明

1. **修改现有项目**
   - 从 `main` 分支新建功能分支进行开发
   - 完成后通过 Pull Request 合并回 `main`，保持主分支稳定
   - 提交信息规范：`feat: / fix: / docs: / test: / chore:`

2. **添加新项目**
   - 在仓库根目录新建 `实训项目N_项目名称` 文件夹
   - 放入项目完整代码（确保已删除子目录中的 `.git` 文件夹）
   - 按照上述提交规范提交并推送

🚀 使用说明

1. 修改现有项目
   - 在 "main"分支外新建功能分支进行开发
   - 完成后合并回 "main"，保持主分支稳定
   - 提交信息规范："feat: 新功能/ fix: 修复/docs: 文档"

2. 添加新项目
   - 在 "main"下新建 "实训项目N_项目名称`"文件夹
   - 放入项目完整代码（删除项目内 `.git`）
   - `git add .` → `git commit` → `git push origin main`
