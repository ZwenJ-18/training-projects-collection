📌 使用说明

1.如何修改已有项目
所有项目均存放在 master 分支的独立文件夹中
修改项目时，建议新建一个分支，修改完成后合并回 master 分支，保持主分支的稳定性
提交信息请遵循规范：feat: 新增功能 / fix: 修复问题 / docs: 更新文档

2.如何添加新项目
在 master 分支下，新建以 实训项目N_项目名称 命名的文件夹
将新项目的所有文件放入该文件夹中（注意删除项目自带的 .git 文件夹）
提交并推送到远程 master 分支
